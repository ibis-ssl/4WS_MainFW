| CAN-01 | 実装済み、混在負荷・停止遅延は未計測 | CAN2の電源基板を含む配線で両バスの帰還間隔・送信周期・キュー破棄を計測する。CAN2の4バイト電圧、未使用C610スロットの0 A、モード離脱・帰還断・共通エラー時の両バスの停止を照合する。[採取手順](atlas_bringup.md#再現用ツール) |

| RESET-01 | 実装・ホスト確認済み、実機未確認 | Mainリセット時にCAN2の電源リセット、各ステア基板のRESET応答と再起動後のFault値、C610の0 Aをキャプチャで照合する。[起動手順](atlas_bringup.md#起動時の周辺基板リセット) |

| IO-01 | 一部実装、回路・用途の照合待ち | PHOTO_0/1、BATT_Vの取得・校正、IMUの機体軸、ブザー以外のPWMの用途と出力条件を確認する。[ハードウェア](hardware.md) |
