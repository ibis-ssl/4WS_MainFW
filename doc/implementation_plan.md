# 実装・検証計画

2026-11-20時点。動作条件は[概要](overview.md)と[現行仕様](README.md)、実施済みの結果は[検証記録](records/README.md)を参照する。

| ID | 状態 | 残る作業と確認条件 |
|---|---|---|
| MOTOR-01 | 実装・ホスト確認済み、Main実機未検証 | SW7のコード3とOLED表示を照合し、単輪ごとに物理位置と正方向、操舵の初期化・角度指令、C610の追従、ボタン解放時の停止を確認する。単輪の確認後に四輪を試す。[結合手順](atlas_bringup.md#実機結合の手順) |
| CAN-01 | 実装済み、混在負荷・停止遅延は未計測 | CAN1の電源基板を含む配線で両バスの帰還間隔・送信周期・キュー破棄を計測する。CAN1の4バイト電圧、未使用C610スロットの0 A、モード離脱・帰還断・共通エラー時の両バスの停止を照合する。[採取手順](atlas_bringup.md#再現用ツール) |
| CM4-01 | 転送条件の確定待ち | SPI2スレーブ設定とCM4_CSの配線・役割を照合し、転送手順を合意する。共通コマンドの反映と128バイト帰還の生成を検証する。[通信の現状](overview.md#通信仕様と実装状況) |
| CTRL-01 | 通常制御は未実装 | 上位・Main・ステアの制御分担、停止・復帰条件を確定する。TIM6の500 Hz入口で帰還の受渡し、制御結果と実行時間を確認する。[コード階層](architecture.md#実行とデータ所有) |
| IO-01 | 一部実装、回路・用途の照合待ち | PHOTO_0/1、BATT_Vの取得・校正、IMUの機体軸、ブザー以外のPWMの用途と出力条件を確認する。[ハードウェア](hardware.md) |

再開時は対象の課題と既存記録を読み、実機条件と完了判定をそろえる。結果は記録に追記し、この一覧は残る作業に更新する。
