# 5方向ボタンとC610全輪操作の検証

2026-11-21のホスト確認。対象は5方向ボタンのビット割当とモーターデバッグ変更。現行の操作は[結合手順](../../atlas_bringup.md#モーターデバッグの操作)、未確認範囲は[実装・検証計画](../../implementation_plan.md)を参照する。

- `Script/build.ps1 -Configuration Debug` と `Script/build.ps1 -Configuration Release` が成功。
- `python ./Script/test_drivers.py` が成功。HALモックで中央・下・右・上・左がbit 0～4に対応すること、操舵対象が単輪でも上下操作が正負方向それぞれで両バスの全4輪を駆動することを確認した。指令の未使用スロットは0 A。
- 操舵対象外の輪が校正中の場合に駆動を開始しないこと、帰還断・モード離脱・共通エラーで両バスへ停止を送ることを確認した。左右の角度指令と中央の初期校正は操舵対象に従うことも確認した。
- 書き込みと実機駆動は未実施。物理ボタンのADC値、OLED表示、各車輪の回転方向と実際の停止時間は未確認。
