# ステアFaultリセット後のCAN／RTT採取

2026-11-21。ユーザーによるリセット後、CAN1（COM12）とCAN2（COM46）をUSB-CAN、MainをRTTで観測した。Mainは `e17e01b` のRelease。ID 0側は保守CANのAXIS読取りでM0/M1の探索段階、ABカウント、Dutyを採取した。採取側が送信したCANフレームは保守読取り要求。

観測を開始した時点でMainは `mode=1 state=2 cal=0 esc=F`。モーターデバッグの待機状態でC610全4輪の帰還があり、操舵の初期校正は未完了だった。

## 解析結果

| 観測区間 | C610 ID 1／2／3／4の帰還件数 | MainのRTT |
|---|---|---|
| 95秒 | 96,685／96,183／96,352／96,510 | 873件、すべて待機 |
| 75秒 | 76,323／75,928／76,056／76,184 | 688件、すべて待機 |

両区間で校正要求 `0x350/0x352` と共通Fault通知 `0x000` は0件。ID 0 M1のABカウントは−2のまま、探索段階・Dutyともに0だった。両ステア基板の校正通知は待機状態を継続した。校正開始が記録されなかったため、前回の原点探索失敗の内訳は未確定。再現確認には記録中に中央ボタンの押下を行い、開始要求からFault直前までを採取する必要がある。

MainのUART4に対応するCOM167はアクセス拒否で開けなかった。Mainの状態は同時採取したRTTで確認した。
